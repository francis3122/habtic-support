# Habtic Privacy & Support

Public privacy-policy and support pages for Habtic.

This repository intentionally contains no application source code and no user data.

## GitHub Pages

Publish the `main` branch from the repository root. The expected URLs are:

- Privacy: `https://francis3122.github.io/habtic-support/privacy/en/`
- Support: `https://francis3122.github.io/habtic-support/support/en/`

Language variants are available under `privacy/zh-hans`, `privacy/zh-hant`,
`support/zh-hans`, and `support/zh-hant`.

Contact: `rancis.contact@rancisstudio.com`
